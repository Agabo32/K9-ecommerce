## 📋 Descripción del Proyecto

**K9 Tires** es una tienda online de neumáticos especializados para equipos de agricultura, construcción, jardín, montacargas y vehículos todo terreno. El e-commerce fue desarrollado con **WordPress + WooCommerce + Elementor Pro**, ofreciendo una experiencia de compra moderna, rápida y orientada a la conversión.

El sitio incluye funcionalidades avanzadas como **financiamiento Buy Now Pay Later** con Klarna, catálogo descargable en PDF, filtros por categoría y rango de precio, y opciones de instalación flexibles para el cliente final.

```
🏢 Marca:       K9 Tires
📍 Mercado:     Estados Unidos (Houston, TX área)
🌐 URL:         https://priory.wisex3.com
🎯 Objetivo:    Venta online de neumáticos industriales y especializados
💳 Pagos:       WooCommerce + Klarna (Buy Now, Pay Later)
```
